Local artifact index

Index a local folder of PAPER report JSON artifacts and summarize diff verdicts (local-only, no upload, no network).

Local-only, read-only folder index.

This page summarizes a local folder of PAPER report JSON that you generate on your own machine. There is no upload, no server, no network, and no wallet, keys, signing, or sending anywhere in this tool. Untrusted report content is escaped and capped — it is displayed, never executed.

How to generate this page

Run the Node-only inspector from the repo root against a local folder of report JSON files.

pnpm web:inspect --dir <folder> --out apps/web/public/research-folder.html --force

Scan a local folder of PAPER report JSON artifacts and render this index. Local-only, no upload, no network; --force overwrites the committed empty-state page.

pnpm web:inspect --dir <folder> --json

Print a machine-readable summary of the folder (counts, by-schema, per-artifact verdicts) to stdout and write no HTML file.

pnpm web:build

Restore the committed empty-state folder index page.

What the folder index summarizes

Conservative, fail-soft scanning of one local directory (no recursion).

  • Reads only local .json files in the folder; non-.json files and subdirectories are skipped with an honest count.
  • Malformed JSON is listed (not interpreted) instead of crashing the scan.
  • Each artifact is labelled by schema (known / unknown / absent) using the same registry as the single-artifact inspector — unknown schemas are never faked.
  • Recognized diff artifacts surface a hasRegression / hasChange verdict; everything else is n/a.
  • Recognized artifacts link to a per-artifact section rendered with the typed inspector view.
  • The loaded index groups the scan into pre-rendered, static filter sections — all / regression / changed / unknown-or-malformed / clean — with no JavaScript and no query params.
  • A paper:sniper:dry-run output folder (recognized by its valid operator bundle) gets a landing overview first: the operator verdict, the artifact chain, route status, and the blocking codes — all read verbatim from the bundle, with a loud SIMULATION-ONLY banner.

Verdict legend

Regression and change verdicts are read straight from each recognized diff artifact — never inferred from text, filenames, or invented fields.

“missing” is never collapsed into “no”. Unknown schemas never produce a verdict.
VerdictMeaning
yesThe artifact's own flag is true.
noThe artifact's own flag is false.
missingThe schema carries this field, but it was absent or not a boolean — never treated as false.
n/aThe schema has no such field (non-diff artifact, or unknown/absent schema).
