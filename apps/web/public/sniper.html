The PAPER sniper command center — candidate intake to operator verdict. Simulation only; live trading stays disabled.

PAPER-only command center — SIMULATION ONLY, by construction.

Everything on this page describes the paper sniper pipeline. There is no wallet, no key, no signing, no transaction, no order anywhere in this system; the route resolver is an honest boundary (always unavailable), and Phase 7 live trading remains disabled and unauthorized. A simulated paper-enter is a classification that always demands operator review — never a trade.

Pipeline

Candidate → Inspect → Risk → Paper decision → Plan → Route boundary → Audit → Handoff → Bundle. Each stage's state is derived from this run's own artifacts.

Candidates complete→Inspect complete→Risk complete→Paper decision review required→Plan complete→Route boundary unavailable→Audit complete→Handoff complete→Bundle blocked
  • Candidates — 2 candidate(s) validated (strict mint checks).
  • Inspect — 2/2 candidates have inspection data.
  • Risk — 2/2 candidates have risk data.
  • Paper decision — 1 paper-enter / 1 watch / 0 reject. Simulated paper-enters always demand operator review.
  • Plan — 1 entr(y/ies) previewed — SIMULATED, never executable.
  • Route boundary — Expected — no route resolver exists inside the simulation boundary; nothing was faked.
  • Audit — Chain audit passed (reports — never authorizes).
  • Handoff — Handoff pack complete (12 roles).
  • Bundle — Operator verdict: blocked — the codes below are the honest record.

Run it yourself

The real-input rehearsal workflow — see examples/sniper/real-input-rehearsal/ for a runnable fictional walkthrough.

pnpm soulmaker token:inspect <MINT> --json --out runs/r/inspect.json

Read-only mint inspection (decimals, supply, mint/freeze authority). Advisory, never a buy signal.

pnpm soulmaker token:risk <MINT> --json --out runs/r/risk.json

Advisory risk report from the real risk engine (flags + score + decision).

pnpm soulmaker paper:sniper:preflight:input:prepare --candidates runs/r/candidates.json --inspect runs/r/inspect.json --risk runs/r/risk.json --out runs/r/preflight-input.json

The bridge: pairs the read-only outputs to your candidates BY MINT (verbatim, fail-closed).

pnpm soulmaker paper:sniper:dry-run --candidates runs/r/candidates.json --preflight-input runs/r/preflight-input.json --adopt-specs --operator <you> --acknowledge-paper-enter-review --out runs/r/out

One command, the whole PAPER chain: 19 artifacts + RUN_SUMMARY.md in one folder.

pnpm web:inspect --dir runs/r/out --force

Render THIS command center over your real run folder (local-only; restore with pnpm web:build).

Phase 7 live-trading posture & operator demo

The honest live-execution status. Nothing here is ready to trade.

Live trading is DISABLED and unauthorized.

The fourteen-condition mainnet live gate defaults blocked, no CLI command can send on mainnet, and the Phase 7 authorization audit verdict is authorized-for-design-only. Two prerequisites remain open before a controlled micro-trade could even be considered: a confirmed devnet broadcast and a written human sign-off. Neither is granted here, and no flag in this repo can substitute for that human decision.
pnpm soulmaker paper:sniper:operator-demo --out runs/demo

Assemble a SAFE demo folder (the real Phase 7 audit + a blank sign-off template + an honest devnet funding-status fixture + the fictional release candidate), every artifact labelled by provenance. Inspect it with pnpm web:inspect --dir runs/demo.

pnpm soulmaker execution:devnet:funding-status --public-key <KEY>

Read the throwaway devnet key's balance and report the honest funding/proof status. Never sends; mainnet endpoints refused.

pnpm soulmaker paper:phase7:signoff:template --out runs/signoff.json

Generate the blank Phase 7 human sign-off template. A signed record is EVIDENCE only — it authorizes no live trade and creates no mainnet send.

pnpm soulmaker paper:phase7:authorization:audit

Re-run the read-only Phase 7 authorization audit. The verdict defaults to not-authorized and authorizes nothing.
