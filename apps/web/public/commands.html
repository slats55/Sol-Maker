Command reference

The real CLI workflows that produce these local artifacts.

pnpm soulmaker <command> [options]

Reference only — the dashboard never runs these.

These commands are run by the operator in a terminal. Read-only chain commands accept public keys only and, in PAPER mode, require an explicit --allow-paper-read. Nothing here signs or sends.
