Command reference

The real CLI workflows that produce these local artifacts.

pnpm soulmaker <command> [options]

Reference only — the dashboard never runs these.

These commands are run by the operator in a terminal. Read-only chain commands accept public keys only and, in PAPER mode, require an explicit --allow-paper-read. Nothing here signs or sends.

Diagnostics

pnpm soulmaker doctor

Environment / config sanity check. No chain, no key.

offline · injected data
pnpm soulmaker config:check

Validate soulmaker.config.json against the safety schema.

offline · injected data
pnpm soulmaker mode

Show the configured mode and its capabilities (read/build/simulate/send).

offline · injected data

Read-only chain

Read-only RPC health / version check. Host-only endpoint display.

Watch a public address: SOL balance + token accounts. Public keys only.

reads chain · public keys only

reads chain · public keys only

reads chain · public keys only

offline · local files only
