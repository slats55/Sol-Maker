Artifact inspector

Inspect one locally-generated PAPER report JSON as a static page (no upload, no network).

Local-only, read-only inspector.

This page renders one local PAPER report JSON that you generate on your own machine. There is no upload, no server, no network, and no wallet, keys, signing, or sending anywhere in this tool. Untrusted report content is escaped and capped — it is displayed, never executed.

How to generate this page

Run the Node-only inspector from the repo root against one local report JSON file.

pnpm web:build

Regenerate every static dashboard page from src/ into apps/web/public/. Offline; reads styles/ and writes public/ only.

pnpm web:inspect --input <report.json> --out apps/web/public/research-artifact.html --force

Read ONE local PAPER report JSON and render it into the artifact inspector page. Local-only, no upload, no network; --force overwrites the committed empty-state page.

pnpm web:inspect --input <report.json> --json

Print a machine-readable summary of the report to stdout and write no HTML file.

What the inspector accepts

Conservative, fail-closed input handling.

  • Exactly one local .json file passed via --input.
  • Recognized PAPER report schemas are badged; unknown schemas are labelled honestly, not faked.
  • Large or deeply-nested data is capped and summarized — the full file is never dumped inline.
  • Directories, non-.json inputs, and malformed JSON are refused with a non-zero exit.
  • See the report viewer for the full catalogue of recognized schemas.

Schema-aware typed views

Recognized PAPER report schemas render a typed summary — identity, key counts, and capped tables — above the generic field view. Unrecognized schemas fall back to the generic view safely.

Typed views are UI-only and defensive: fields are read from the parsed JSON, escaped, and capped. There is no backend import, no upload, and no network; report content is displayed, never executed. Missing or type-mismatched fields render as “—” with a visible partial-view notice.
