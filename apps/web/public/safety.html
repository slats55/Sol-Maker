What each mode means

PAPER
active Default. Fully simulated, offline, no key, no chain access — the only honest live posture this dashboard has today.
WATCH_ONLY
available Reads public chain state with public keys only. Refuses secret-length input. No build, simulate, or send.
SIMULATION
available Builds and simulates transactions for human-readable preview only — never sends. Roadmap Phase 6, not started.
DANGEROUS_BURNER_LIVE
gated Burner-only live sending behind every fail-closed gate. Roadmap Phase 7 — not started and not reachable from this UI.

Hard guarantees — what this dashboard will never do

  • Connect a wallet or hold a private key
  • Accept or derive from a seed / recovery phrase
  • Use the operator's main wallet
  • Sign, send, build, plan, or simulate a transaction
  • Auto-approve anything or send to an unseen address
  • Fetch live market data, scrape, or call a trading / data provider
  • Show fake balances, fake PnL, or a fake 'connected' / 'running' state

Live-mode gate (fail-closed)

Every condition must hold before any future signing/sending code could run. The gate fails closed. Roadmap Phase 7 — not started.

  • mode === DANGEROUS_BURNER_LIVE
  • killSwitch === false
  • live.acknowledgeBurnerRisk === true
  • live.confirmFreshBurner === true
  • live.burnerKeyEnvVar is set AND that env var is present
  • out-of-band env SOULMAKER_I_UNDERSTAND_BURNER_RISK === "true"
  • caps within the hard limits (HARD_LIMITS)
