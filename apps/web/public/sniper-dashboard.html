Live Canary

Preparing and signing a canary is intentionally NOT on this dashboard. When a candidate is canary-eligible:

  1. Run soulmaker live:canary:prepare --out request.json … to build the UNSIGNED request.
  2. Open the Live Console, connect Phantom on mainnet, and verify mint / amount / slippage.
  3. Arm, then confirm in Phantom. You are the only signer.
